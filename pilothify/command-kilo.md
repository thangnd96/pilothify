description: Build or query a pilothify knowledge graph
---

Invoke the `pilothify` skill immediately.

Pass the full `/pilothify` argument string through unchanged.
If no arguments were supplied, treat the target path as `.`.

Examples:
- `/pilothify`
- `/pilothify src --update`
- `/pilothify query "what connects auth to billing?"`

Do not answer from raw files before handing off to the `pilothify` skill.
